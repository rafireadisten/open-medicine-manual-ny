# OMM-NY 26-week curriculum

One session per week, approximately 75% outpatient / 25% inpatient overall, with critical organ systems prioritized. Each weekly file is a **draft outline**, not a completed clinical lesson. Each topic requires a civilian L1-L4 reference map, a separate VA/DoD reference track where applicable, fundamental guidance highlight, X1 primary supporting study, and PICOT summary. Evidence and clinical approval are tracked independently.
