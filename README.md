# Open Medicine Manual NY (OMM-NY)

Version-controlled medical education and clinical reference manual.

## Scope
- 26-week Internal Medicine Review Course (one session per week)
- Approximately 75% outpatient / 25% inpatient
- Adult internal medicine, basic OB/GYN, and basic surgical principles
- Civilian L1-L4 reference tiers, plus a separate VA/DoD reference track

## Evidence standard
For **each actual reference document**, select ONE fundamental clinical guidance point, identify ONE directly supporting primary study (X1), and summarize the study using PICOT (Population, Intervention, Comparator, Outcomes, Time). Record effect sizes, uncertainty, source links, document version, and human review status. Do not fabricate evidence or treat empty references as completed.

## Agent policy
MCP-assisted work stays within this repository and authorized tools. Keep auditable progress and human approval gates. No PHI, no unauthorized repository changes, no clinical validation without clinician review.

## Status
This is an initial publication. A separate project archive contains further curriculum modules and supporting files; the GitHub tree should not be considered complete until they are imported and verified.

Educational resource only. Recheck up-to-date primary sources and institutional protocols before clinical use.
