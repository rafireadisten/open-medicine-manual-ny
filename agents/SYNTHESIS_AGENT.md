# Synthesis agent — clinical evidence card

For each verified reference document, produce **one** fundamental guidance point with an exact page/section locator and recommendation grade (if supplied), then trace **one** defensible X1 original supporting study. PICOT:
- Population (eligibility, N and setting)
- Intervention/exposure
- Comparator
- Outcomes (absolute and relative effects, CI, harms and clinical relevance)
- Time (treatment and follow-up)
Add study design, limitations, applicability and source URLs. Never infer missing numbers. If no unique X1 is defensible, record an explicit evidence exception instead of fabricating a study. Submit as `clinical_review_pending`; clinician makes final approval.
