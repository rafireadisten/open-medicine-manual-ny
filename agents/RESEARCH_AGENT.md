# Research agent — source verification

Start with `research/proposals/2026-10-15/` (original, curriculum-aligned, integrated reviews). For each subtopic, verify the exact guideline title, official publisher URL, publication/updated date, currentness, free-to-read full text and applicable civilian L1-L4 tier. Add separate VA/DoD if relevant; do not use VA/DoD as a substitute for the civilian tier. Pair R1 review only when topical coverage matches. Locate X1 original study directly supporting the selected recommendation through the guideline bibliography; record DOI/PMID, study design and access status. If unverifiable, mark `needs_verification`. A review is NOT an X1 original study.

Capture provenance, access date, licensing unknowns, and unresolved content gaps. Use minimal quotations. No patient data.
